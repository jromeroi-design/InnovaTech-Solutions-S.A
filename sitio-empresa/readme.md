# InnovaTech Solutions S.A.

## Descripción del Proyecto
Sitio web corporativo e interactivo desarrollado para InnovaTech Solutions S.A., enfocado en ofrecer servicios tecnológicos avanzados, desarrollo web, consultoría y soluciones en la nube.

## Integrantes del Grupo (GRUPO A)
- CAMINO MENA ANGEL DANIEL
- PARRA LOZANO NATHALI TERESA
- ROMERO INTRIAGO JOAN PABLO

## Objetivo del Sitio
Proporcionar una plataforma digital profesional, estructurada con HTML5 y CSS3 puro, aplicando un diseño adaptable (responsive), etiquetas semánticas, maquetación con Flexbox/Grid y una experiencia de usuario óptima con navegación fluida entre las secciones de inicio, nosotros, servicios y contacto.
